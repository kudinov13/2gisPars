# ParserCompany — парсер компаний по 2GIS

Десктопное приложение для поиска компаний по 2GIS. Ищет по городу **или** по региону (республика / область / край), фильтрует по мессенджерам (VK/Telegram/WhatsApp) и телефону, проверяет сайты на ошибки, определяет возраст компании. Экспортирует результаты в Excel.

**Бесплатно. Без API-ключей. Работает через скрапинг Chrome.**

---

## Возможности

- Поиск по **городу** или **региону** (республика, область, край) — с автоматической фильтрацией результатов по адресу
- Фильтр: наличие телефона и/или мессенджера (VK / Telegram / WhatsApp)
- Аудит сайтов: HTTPS, мобильная версия, мета-теги, аналитика, скорость загрузки, robots.txt, sitemap.xml
- Определение возраста компании (RDAP — возраст домена, VK API — возраст группы)
- Фильтр «молодые компании» (до N месяцев с момента открытия)
- Пропуск компаний с хорошими сайтами
- Экспорт в Excel (.xlsx) с цветовой разметкой

## Требования

- **Python 3.10+**
- **Google Chrome** (установленный в системе)

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/kudinov13/2gisPars.git
cd 2gisPars
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Установить браузер для Playwright

```bash
playwright install chromium
```

> Это скачает Chromium (~170 МБ). Нужно сделать **один раз** после установки.

## Запуск

### Десктопное приложение (рекомендуется)

```bash
python desktop_app.py
```

Откроется нативное окно приложения с графическим интерфейсом.

### Веб-версия (в браузере)

```bash
python app.py
```

Затем откройте [http://127.0.0.1:18923](http://127.0.0.1:18923) в браузере.

### Консольный режим

```bash
# Поиск по городу
python main.py --city "Новосибирск" --rubric "стоматология"

# Поиск по региону
python main.py --region "Республика Алтай" --rubric "турбаза"

# С фильтром молодых компаний и VK-токеном
python main.py --city "Москва" --rubric "ремонт квартир" --only-young --young-months 12 --vk-token "ВАШ_ТОКЕН"

# Без фильтров (все компании)
python main.py --city "Краснодар" --rubric "кафе" --no-messenger-filter --no-phone-filter
```

## Использование интерфейса

### Поле «Республика / Область / Край»
Введите регион для поиска по всему субъекту РФ, например:
- `Республика Алтай`
- `Краснодарский край`
- `Новосибирская область`
- `Республика Татарстан`

> Если это поле заполнено — поле **Город** игнорируется автоматически.

### Поле «Город»
Используется если поле региона **пустое**. Введите название города:
- `Новосибирск`
- `Горно-Алтайск`
- `Москва`

### Поле «Сфера деятельности»
Рубрика для поиска — любой текст как в поиске 2GIS:
- `стоматология`
- `турбаза`
- `ремонт квартир`
- `автосервис`

### Фильтры
| Фильтр | Описание |
|---|---|
| Наличие мессенджера | Оставить только компании с VK / Telegram / WhatsApp |
| Наличие телефона | Оставить только компании с указанным телефоном |
| Только молодые компании | Компании не старше N месяцев |
| Проверять сайты | Аудит сайта на технические проблемы |
| Пропускать хорошие сайты | Скрыть компании без значимых проблем |

### VK токен (опционально)
Нужен только для определения возраста компании через VK-группу.
1. Перейдите на [https://vk.com/dev](https://vk.com/dev)
2. Создайте Standalone-приложение
3. Получите сервисный токен и вставьте в поле

## Результаты

После завершения парсинга:
- Таблица с результатами отображается прямо в приложении
- Кнопка **↓ СКАЧАТЬ EXCEL** — скачать отчёт `report.xlsx`
- Клик по строке в таблице — развернуть детали (контакты, проблемы сайта, адрес)

## Известные ограничения

- При слишком активном парсинге 2GIS может показать антибот-страницу (обрабатывается автоматически)
- Возраст домена работает не для всех доменов (.ru через RDAP может не отдавать дату)
- VK API: не более 3 запросов в секунду
- Скорость: ~30–100 компаний в минуту в зависимости от сети и ответа 2GIS
